# CS 002A Programs

These are all of the c++ programs I wrote for my first object-oriented programming class.
This course was taken from Foothill College @ Los Altos Hills, California.

Thank you Professor Meade.

## Running the Programs
All programs are pre-compiled adjacent to its source code and can be ran from the command line.
- The only exception is `module-11/ai-ui-assignment`, which can simply be started by opening the html file in a browser.

Example (assuming you're in the program's directory):
```
cd module-1
./shape-shifter-challenge (file without the .cpp extension)
```
